# Accessibility and UI/UX Audit

1. **Environment Setup**: Run the local development server using the appropriate terminal command (e.g., `npm run dev`).
2. **Browser Interaction**:
   - Open the **Antigravity Browser** to the local dev URL.
   - Navigate through the primary user flows (e.g., Home -> Login -> Dashboard).
3. **Audit**:
   - Check for ARIA labels, color contrast, and keyboard navigability.
   - Identify any UI inconsistencies or broken layouts.
4. **Report**: Save screenshots of identified issues as Artifacts and provide a summary of suggested fixes.
