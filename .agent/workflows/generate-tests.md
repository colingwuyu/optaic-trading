# Generate and Validate Unit Tests

1. **Analysis**: Examine the current active file or provided directory to identify all public methods, components, and logic blocks.
2. **Implementation**: 
   - Generate unit tests for each identified element.
   - Name test files using the `test_` prefix (e.g., `test_logic.py`) or `.test` suffix (e.g., `logic.test.ts`).
   - Use the project's existing testing framework (e.g., PyTest, Jest, or Vitest).
3. **Execution**: Run the newly created tests in the terminal.
4. **Verification**: 
   - Ensure all tests pass with 0 errors.
   - Resolve any warnings (deprecation, linting) before reporting completion.
